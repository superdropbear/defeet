# Synthetic seed images

These files were generated as neutral, non-explicit anatomy/reference images
of fictional adults. They must still be manually reviewed before deployment.

| File | Composition |
|---|---|
| `df_ai_0001.png` | Seated on a linen sofa, three-quarter view |
| `df_ai_0002.png` | Standing on a pale wood floor, oblique view |
| `df_ai_0003.png` | Walking at a beach, low side view |

Generation constraints included: fictional adult subject, face outside frame,
neutral pose, no celebrity resemblance, no sexual context, no text/watermark,
and anatomically correct feet. The built-in image generation tool was used.
